你好，我是尤运宁，一名 Agent 开发工程师，关注大模型基础设施、Agent 产品设计和源码实现。

我熟悉 vLLM、kvcached、Pi Agent、Claude Code 等产品和技术，能够从产品设计、系统架构到源码实现分析完整技术链路，也具备 iOS 开发和银行核心系统运维开发经历。

我的技术方向包括大模型推理、KV Cache、Agent 工具调用与编排、开发者工具、Swift、UIKit、SwiftUI、Combine、RxSwift、MVVM、Clean Architecture，以及 Fastlane 和 CI/CD 工程化。

此前我在武汉农村商业银行总行信息科技部负责运维开发，在中国地质大学（武汉）获得计算机技术硕士学位，并发表过 3 篇 SCI 一区论文。我的项目经历包括：

- NanoPineapple：AI 图像生成应用的 iOS 端开发，负责架构、核心功能和性能优化。
- EasyResume：简历制作与 AI 优化工具，独立完成产品设计、开发和上架。
- [AITextView](https://github.com/youyinian288/AITextView)：基于 WebKit、Swift 和 Markdown-it 的流式 Markdown 渲染引擎。
